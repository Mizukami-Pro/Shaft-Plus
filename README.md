# shaft+

**更方便地管理自己收藏的所有内容。**

收藏多了之后，只记得某个角色、题材或作者，却不记得当时把作品收藏在哪里。shaft+ 把插画、漫画、动图和小说收藏汇总到「全收藏分类」，先按作品标签找到一批相关收藏，再用搜索、筛选和排序找回目标作品。

本项目基于 Pixiv-Shaft classic 4.9.7，重点增加收藏管理能力。这里介绍的是 shaft+ 新增内容；原版已有功能请参考[原项目](https://github.com/CeuiLiSA/Pixiv-Shaft)。

下面分别说明用途、操作方式和实际场景。

## 全收藏分类：先看清自己都收藏了什么

从侧边栏或「我的」页进入 **全收藏分类**，应用会逐页同步当前账号的收藏，把不同类型作品已有的标签汇总到同一个页面。你不必分别打开插画收藏和小说收藏，也不用先手工给每件作品重新分类。

页面按命中作品数排列标签，并显示收藏总量、作品类型统计和标签数量。例如，你收藏的插画、漫画和小说中都有「初音ミク」，这里会汇总这个标签；点击后就能一起查看相关作品，再按需要切换作品类型。

- **搜索标签**：输入标签原名或译名，例如「初音」或「原创」，快速找到对应分类。
- **选择统计范围**：通过「包含非公开收藏」开关，决定是否把非公开收藏一起纳入当前列表和统计。
- **边同步边查看**：首次收藏量较大时，页面会显示同步进度。已经同步的内容可以先查找，完整统计需要等同步完成。

这里的分类来自**作品已有标签**，提供汇总和查找入口；不会自动修改作品标签或收藏的公开状态。

## 同步与刷新：不用为了分类反复手动翻页

「全收藏分类」接入原版本地收藏镜像，新增了统一的同步状态与汇总入口。第一次进入后会逐页拉取当前范围的收藏，页面显示已同步件数、正在处理的公开 / 非公开书架，以及是否已经全部同步。

- **先用已有数据**：同步尚未完成时，已经拉取的标签和作品会陆续出现，可以先搜索、筛选和浏览。
- **慢速后台同步**：收藏量较大时需要等待，遇到 Pixiv 限流会显示暂缓状态，冷却后继续。
- **主动更新**：在网页或其他客户端新增收藏后，可使用下拉刷新或「立即刷新」请求更新。
- **范围跟随账号与开关**：查看当前登录账号的收藏；是否纳入非公开收藏由页面开关决定，排行海报也跟随该范围。

这是把原版镜像能力接入新的全收藏管理页面；标签数量与排行以当前已同步结果为准。

## 搜索与筛选：在一大批收藏中找回想要的作品

点击某个标签后，详情页会列出你已收藏、且带有该标签的作品。你可以继续按**标题、作者或标签文字（含译名）**搜索；多个词用空格分开时，会同时匹配这些条件。输入纯数字还可以按作品 ID 或作者 UID 查找。

因此搜索分两层：总览页用来「找标签」，详情页用来「在这个标签下找作品」。例如先搜「初音」进入角色分类，再输入作者名，就只看自己收藏中与该角色和作者同时相关的作品。

详情页可在「全部 / 插画 / 漫画 / 小说 / 动图」之间切换，**插画和动图可分别查看**。选择「全部」时，图片作品与小说一起列出，小说使用整行卡片，方便同一个主题下交叉浏览。

例如，想找「以前收藏过的某个角色的漫画」，可以先搜索角色标签，点进标签后选择「漫画」，再输入记得的作者或标题词。如果记不清名字，还可以用投稿时间、页数等条件继续筛选。

筛选面板支持把多个条件组合使用：

| 条件 | 适合怎么找 |
| --- | --- |
| 投稿期间 | 最近一周、一月、半年、一年或自定义起止日期，依据作品投稿时间。 |
| 收藏数 | 选择 1000+ 等档位，或自定义一个作品总收藏数区间。 |
| users入り 标签 | 按作品携带的 `1000users入り` 等标签阈值筛选；与上面的作品总收藏数分开。 |
| 长宽比 | 选择横图、竖图或正方形图。 |
| 分辨率 | 选择宽高均为 3000px 及以上、1000～2999px，或 999px 及以下的图片。 |
| 页数 | 区分单页与多页作品，例如优先找多页漫画。 |
| AI 作品 | 选择全部、不显示 AI 或仅看 AI 作品。 |
| R18 范围 | 选择全部、仅安全内容或仅 R18 内容。 |

**选择条件即生效**，列表和命中件数随之更新；入口会提示当前启用了几项条件。「完成」关闭面板，「重置」只清面板内的八项条件，保留已输入的关键词和作品类别。当前查询条件在旋转或重建页面时会恢复。

这些操作用于**当前标签下已同步到本地的个人收藏**，适合逐步缩小范围。

## 五种排序：换个角度重新浏览收藏

同一个标签下，可以按不同方式重新排列作品。想回顾早期投稿、先看热门作品，或找相对较新的高收藏作品，都可以切换排序：

| 页面选项 | 排序依据 |
| --- | --- |
| 最新发布 | 作品投稿时间从新到旧。 |
| 最早发布 | 作品投稿时间从旧到新。 |
| 最多收藏 | 作品在 Pixiv 上的总收藏数从多到少。 |
| 热度 | 作品浏览量从多到少。 |
| 趋势 | 用作品总收藏数除以发布至今的天数，估算平均收藏速率。 |

时间排序依据是**作品投稿时间**。例如「最早发布」会把较早投稿的作品排在前面，不代表你最早收藏的作品；「趋势」是平均速率估算，不是实时新增收藏榜。

## 我的 Tag 排行：把收藏偏好做成一张海报

在全收藏分类页打开 **我的 Tag 排行**，应用会统计你收藏的作品最常带有哪些标签，并生成可以保存、分享的海报。它展示的是「我的收藏偏好」，不是 Pixiv 全站的热门标签排行。

- **TOP 6**：突出出现最多的六个标签，适合分享一眼能看懂的偏好摘要。
- **TOP 20**：展示更多标签，适合回顾自己的题材、角色和画风偏好。
- **可选账号和头像**：生成前决定是否在海报上展示个人信息。
- **保存与分享**：保存到相册，或通过系统分享菜单发送给其他应用。

例如，排行中的「初音ミク · 23 件作品」，表示当前统计范围内有 23 件已同步收藏带这个标签。一件作品可以带多个标签，因此各标签的数量相加不等于收藏总数。建议首次同步完成后再生成海报，让结果覆盖全部收藏。

## 原图与预览：在详情页直接切换，并记住偏好

经典详情页与 V3 详情页新增常驻的 **查看原图 / 返回预览** 按钮，需要看线条和细节时直接加载完整分辨率图，随后也能切回预览。原来的菜单入口也改为同一套双向切换。

- **与设置同步**：详情页按钮与「详情页直接加载原图」使用同一份偏好，在任一处修改都会同步。
- **记住选择**：翻到相邻作品、再次打开详情页，或从设置返回时，会按当前选择加载。
- **保留当前页**：多页作品切换清晰度时保留所处页面，平板作品区也跟随切换。
- **按适用范围显示**：动图与本地快照不显示这个入口；默认仍使用预览图，由你决定何时加载原图。

## 小说翻译：底栏可见，进度、续翻和显示方式一起接通

本次把原版已有的小说全文翻译能力接到阅读器底栏，按钮会根据状态直接告诉你下一步能做什么：

| 当前状态 | 按钮与点击结果 |
| --- | --- |
| 尚未翻译 | 显示「翻译」，点击开始全文翻译。 |
| 正在翻译 | 显示「翻译中 xx%」，点击可查看已完成段数；不会重复启动任务。 |
| 翻译中断 | 显示「继续翻译」，可续翻，也可选择已有译文的显示方式。 |
| 已有译文 | 显示「译文」，点击在仅原文、仅译文、双语对照之间选择。 |

例如，长篇翻译中断后，你可以从底栏继续处理，而不必重新到顶栏菜单查找入口。字体、排版和主题功能沿用原版；这里新增的是快捷入口、进度展示和状态联动。

## 开始使用

1. 登录自己的 Pixiv 账号，从侧边栏打开「全收藏分类」。
2. 按需选择是否包含非公开收藏，等待后台同步；收藏较多时可以先浏览已同步内容。
3. 搜索或点选标签，在详情页组合使用作品类型、关键词、筛选和排序。
4. 想回顾整体偏好时，回到总览页生成「我的 Tag 排行」海报。
